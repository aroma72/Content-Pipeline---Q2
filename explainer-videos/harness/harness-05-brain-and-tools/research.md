# Research Brief — "Choosing a brain & using tools" (Harness series, V5)

Audience: beginners. ONE concept: **a good room makes three "right" choices for the brain — the
right brain (model routing), the right tools (tool execution), and the right context (what it's
shown).** "A brain is as good as what the room hands it." Does NOT overlap evals or autonomy; and
carefully distinguishes its "context/memory" (what the brain is SHOWN each turn + durable facts)
from V4's "state/memory" (where the JOB is).

## Verified facts to teach (each sourced)

1. **Model routing (the right brain).** The model-abstraction layer does routing, fallback, and
   "capability-aware selection" so different workflow steps can use different models based on task
   requirements — a cheap/quick model for easy steps, a stronger one for hard steps.
   — balaji bal, *Agentic Harnesses* (Medium), 2026.
   https://medium.com/@balajibal/agentic-harnesses-the-new-infrastructure-layer-for-ai-systems-3939c6fac1a6

2. **Tool execution (the right tools, used right).** The tool layer gives "controlled access" to
   capabilities (files, terminals, APIs) and "enforces permissions, schemas, validation, and
   execution policies so that tool use remains bounded and inspectable." Each tool comes with a rule
   for correct use, and the room can check what it did. — balaji bal (Medium), 2026.

3. **Context & memory (the right thing to show).** The context layer assembles what the model
   actually sees: "prompt templates, task instructions, retrieved documents, summaries, prior
   actions, long-term memory, environment snapshots." Show the right slice for this step, not
   everything; keep a few durable facts for next time. — balaji bal (Medium), 2026.

4. **Model is a small slice (callback).** The brain does the thinking, but the room decides what it
   thinks about — which is why the same model can feel brilliant in one room and lost in another.
   (Ties to V1's "~a tenth is the brain".) — MindStudio, 2026.

## Chosen analogy (extends V1–V4)

- **The room hands the brain three things.** Right brain (a small orb for small jobs, a bigger orb
  for the hard one), right tools (a calculator, the files, a phone — each with a rule for using it),
  and right context (the right notes/pages for THIS step, plus a few lasting facts). Keep orb = brain,
  room = harness.

## Learner misconceptions to pre-empt → failure-mode beat

1. **"Use the biggest model for everything."** No — the room routes: small brain for easy steps,
   strong brain for hard ones (fact 1).
2. **"A tool is just a feature."** No — a tool comes with a rule for correct use and is checkable, so
   the room stays bounded and inspectable (fact 2).
3. **"Show the model everything you know."** No — too much context loses the thread; hand it the right
   slice for this step (fact 3). (Failure-mode beat: show too much → it loses the thread.)

## On-screen numbers
- None. Mechanism video. Clean three-part recap list.

## Best teaching technique

**Three "right" choices, one per part.** Right brain → right tools → right context, each shown with
one small concrete example, then the payoff line: "the brain thinks; the room decides what it thinks
about." Keep tool "rules" about correct/inspectable use, NOT autonomy/permission levels (that's the
autonomy module).
