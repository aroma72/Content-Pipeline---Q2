0:20–1:20THE PATTERN (4 SIMPLE STEPS)
[VISUAL: Four steps appearing on screen, each with an icon]

Step 1: Find something you're doing repeatedly.

Look at your week. What are you doing more than once?

Writing similar emails? Summarizing documents? Extracting data? Generating ideas? Organizing information?

That repetition is your opportunity.

Step 1: Identify the Repeating Task

Think: "What do I do every week that takes time and I hate doing manually?"

Step 2: Define what the system receives and what it outputs.

If you're summarizing documents: System receives documents. System outputs summaries.

If you're generating content: System receives a topic. System outputs content.

Be specific. Input → Output. That's your interface.

Step 2: Define Input and Output

Input: [What does the system receive?] → Output: [What should it produce?]

Step 3: Build the agent.

Use Claude. Use agentic frameworks. Chain prompts together. Get the agent to do what you did manually.

It won't be perfect the first time. That's okay. Iterate.

Step 3: Build the Agent

Write prompts. Test outputs. Refine. Make it work.

Step 4: Put it somewhere it runs automatically.

Scheduled? Triggered by an event? In a pipeline with other agents?

The key is: You don't run it manually. It runs without you.

Step 4: Automate It

Schedule it. Trigger it. Hook it into a pipeline. Make it work without you.

1:20–2:20A REAL EXAMPLE
[VISUAL: Show the example workflow visually - emails coming in, agent processing, summaries coming out]

Let me make this concrete.

You get 20 customer support emails every day. You read them. You write summaries for your team. Every day. Repetitive.

Step 1: You identified the repeat task. Email summarization. ✓

Step 2: Input = emails. Output = summaries. ✓

Step 3: You write an agent that reads emails and generates summaries. You test it. Refine the prompt until the summaries are good. ✓

Step 4: You schedule it to run every morning at 9am. Or you trigger it whenever new emails arrive. Either way, summaries appear automatically. ✓

Result: What used to take 1 hour every day now takes 0 hours. The agent does it. You woke up. Summaries were waiting.

That's producing. You invested upfront. Now the system pays dividends.

And here's the real power:

Once you have that system, what's next? You build another. A system that takes those summaries and creates action items. Or escalates urgent emails.

Now the systems talk to each other. They compound. Your email processing is fully automated.

That's the producer path. One system feeds another. Everything compounds.
