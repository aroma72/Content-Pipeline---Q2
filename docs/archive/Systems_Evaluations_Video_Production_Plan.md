## PART 2: VIDEO SEGMENTATION STRATEGY

### How to Break the 90-Minute Session into 4 Videos

**Session Total**: Systems Evaluations Learner Content (90 minutes)

**Breakdown Strategy**:

| Video | Title | Duration | Coverage | Primary Audience |
|-------|-------|----------|----------|------------------|
| **1** | What is Systems Evaluation? | 12 min | Concepts, definitions, why it matters | All learners |
| **2** | MEASURE Framework & Evaluation Types | 13 min | 5-step loop, metrics vs checks vs human eval | All learners |
| **3** | Designing Metrics That Matter | 12 min | How to design metrics, code examples | Technical learners |
| **4** | Continuous Improvement in Production | 13 min | Real case study, how to iterate | Advanced/practitioners |

**Content Flow**:
```
Conceptual → Tactical → Practical → Real-World Application
Video 1       Video 2      Video 3      Video 4
(Why)         (What)       (How)        (Where)
```

**Why This Segmentation Works**:
- ✓ Progressive learning (simple → complex)
- ✓ Natural topic breaks (not arbitrary)
- ✓ Each video stands alone but builds on previous
- ✓ Respects cognitive load (12-15 min = optimal learning window)
- ✓ Allows for different pacing/styles per video

**Repurposing Strategy**:
- **Video 1**: 3 clips (Definition, Testing vs Eval, Why It Matters)
- **Video 2**: 4 clips (MEASURE intro, 5 steps, 3 types, Hybrid approach)
- **Video 3**: 3 clips (Design process, Metrics examples, Dashboard)
- **Video 4**: 3 clips (Case study part 1, 2, 3, Production reality)
- **Total**: 13 short-form clips (3-5 min each) for social/LMS

### Phase 2: Production (Weeks 3-5)

#### Week 3: Voiceover Recording

**Process**:
1. Read through full script 3-5 times (get comfortable)
2. Record each scene separately (easier to re-record problem areas)
3. Record in quiet space with quality microphone
4. Save each scene as separate audio file
5. Log timings (how long each scene takes to read)

**Recording Checklist**:
```
[ ] Quiet recording space (minimal echo)
[ ] High-quality microphone (USB or XLR)
[ ] Pop filter (reduces plosives)
[ ] Headphones (monitor quality during recording)
[ ] Recording software (Audacity free, Adobe Audition pro)
[ ] Raw files backed up
[ ] Timings logged for each scene
```

### Phase 3: Post-Production (Weeks 6-7)

#### Week 6: Video Editing

**Editing Process for Each Video**:

1. **Assembly Edit** (first pass)
   - Sync voiceover with visuals
   - Place animations and graphics
   - Arrange B-roll
   - Add basic transitions

2. **Fine Edit** (refine timing)
   - Trim voiceover dead air
   - Sync animations with narration
   - Adjust pacing
   - Verify continuity

3. **Polish Edit** (final touches)
   - Color grading (match mood board colors)
   - Audio mixing (balance voiceover, music, SFX)
   - Add captions/subtitles
   - Add motion graphics polish

**Editing Software Options**:
- **Free**: DaVinci Resolve (professional, free version)
- **Accessible**: iMovie (Mac) or Windows Photos (PC)
- **Professional**: Adobe Premiere Pro or Final Cut Pro

#### Week 7: Sound & Music

**Audio Mixing**:
- Normalize voiceover level
- Add background music (20-40% volume under voice)
- Add sound effects (transitions, emphasis)
- EQ voiceover for clarity
- Master to final output levels

**Music Selection**:
- **Free sources**: Epidemic Sound, Artlist, Pixabay Music
- **Criteria**: Professional, energetic, not distracting
- **Recommendation**: 1-2 main tracks (variety between videos if appropriate)
- **Rights**: Verify all music is royalty-free for educational use

**Sound Effects**:
- Transition sounds (smooth, subtle)
- Emphasis sounds (concept introduction)
- Success/error sounds (for code execution scenes)
- Subtle ambient sound (silence is okay, but minor ambient adds polish)

### Phase 4: Quality Assurance & Finalization (Week 8)

#### Review Checklist

**Technical Quality**:
- [ ] Video resolution: 1920×1080 minimum (4K ideal)
- [ ] Frame rate: 24fps or 30fps consistent
- [ ] Audio: Clear, no background noise, properly balanced
- [ ] Lip sync: Voiceover matches onscreen speaker (if present)
- [ ] Colors: Consistent with mood board
- [ ] Text readability: All text legible at 1080p

**Content Quality**:
- [ ] Script accuracy (no errors, correct terminology)
- [ ] Examples clarity (easy to follow)
- [ ] Pacing (not too fast, not too slow)
- [ ] Transitions (smooth, not jarring)
- [ ] Animations (smooth, professional)
- [ ] Consistency (style, tone, terminology across all 4 videos)

**Accessibility**:
- [ ] Captions/subtitles complete and accurate
- [ ] Audio descriptions for complex visuals
- [ ] Color contrast (readable for color-blind viewers)
- [ ] Text size (readable)
- [ ] Audio quality (clear for hearing-impaired with captions)

**Testing**:
- [ ] Watch entire video (catch any issues)
- [ ] Test on different devices (phone, tablet, desktop)
- [ ] Test audio on different speaker types
- [ ] Verify all links/resources in description work
- [ ] Get feedback from 2-3 test viewers
