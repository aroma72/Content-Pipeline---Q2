# Systems Evaluations Video Series — Mood Board Specification
**Professional Visual Identity Guide for 4-Part Video Production**

---

## Executive Summary

This document defines the complete visual identity and aesthetic guidelines for the Systems Evaluations video series. It ensures visual consistency, professional appeal, and pedagogical clarity across all 4 videos and 13 short-form clips.

**Primary Objective:** Create a modern, data-driven aesthetic that reinforces systems thinking, continuous improvement, and technical credibility while remaining accessible to diverse learners.

---

## 1. Core Visual Identity

### 1.1 Design Philosophy

**Three Pillars:**
- **Clarity**: Every visual choice should reduce cognitive load and support learning
- **Dynamism**: Animation and motion convey systems in action (loops, flows, feedback)
- **Professionalism**: Technical credibility through clean design, proper data visualization, and sophisticated typography

**Emotional Tone:**
- Approachable but authoritative
- Energetic but calm (not overwhelming)
- Modern but timeless
- Scientific yet human-centered

### 1.2 Visual Metaphors

**Primary Metaphor: The MEASURE Loop**
- Visual representation of circular/cyclical processes throughout
- Emphasis on feedback, iteration, continuous improvement
- Systems thinking visualization (inputs → processes → outputs → feedback)

**Secondary Metaphors:**
- Layered evaluation (onion/nested circles for types of evaluation)
- Metrics dashboards (data-driven decision making)
- Network connections (systems relationships and interdependencies)

## 2. Color Palette

### 2.1 Primary Colors

**Deep Navy Blue** `#1F3A5F`
- Represents: Authority, trust, systems depth
- Usage: Headers, key diagrams, primary elements
- Hex: #1F3A5F | RGB(31, 58, 95) | CMYK(67, 39, 0, 63)

**Teal Accent** `#17A2B8`
- Represents: Action, growth, continuous improvement
- Usage: Highlights, CTAs, improvement cycles, animation elements
- Hex: #17A2B8 | RGB(23, 162, 184) | CMYK(88, 12, 35, 28)

**Bright Green** `#28A745`
- Represents: Success, positive metrics, completion
- Usage: Success states, positive indicators, achieved milestones
- Hex: #28A745 | RGB(40, 167, 69) | CMYK(76, 0, 59, 35)

**Warm Orange** `#FD7E14`
- Represents: Action needed, attention, areas for improvement
- Usage: Alerts, needs-improvement metrics, emphasis
- Hex: #FD7E14 | RGB(253, 126, 20) | CMYK(0, 50, 92, 1)

**Cool Gray** `#495057`
- Represents: Context, supporting information, neutral elements
- Usage: Secondary text, dividers, supporting graphics
- Hex: #495057 | RGB(73, 80, 87) | CMYK(16, 8, 0, 47)

**Light Background** `#F8F9FA`
- Represents: Clean space, focus, minimal distraction
- Usage: Slide backgrounds, content containers
- Hex: #F8F9FA | RGB(248, 249, 250) | CMYK(1, 1, 0, 2)

### 2.2 Color Combinations

**Primary Combination (for main slides):**
- Navy (#1F3A5F) + Teal (#17A2B8) on Light Gray background (#F8F9FA)
- Example: Navy headers with teal accent lines, text on light background

**Data Visualization Palette:**
- Success metrics: Bright Green (#28A745)
- Improvement areas: Warm Orange (#FD7E14)
- Neutral/context: Cool Gray (#495057)
- Baseline/target: Navy (#1F3A5F)

**Accent Combinations:**
- Navy (primary) + Teal (action highlight)
- Navy (primary) + Green (success states)
- Navy (primary) + Orange (attention states)

### 2.3 Accessibility Considerations

- All text-background combinations meet WCAG AA contrast requirements (4.5:1 for body text)
- Avoid navy-on-teal combinations for text (insufficient contrast)
- Use teal as accent, navy for text-heavy content
- Orange/gray text pair on navy/light backgrounds for maximum accessibility

## 3. Typography

### 3.1 Font Selections

**Primary Font: Inter (Modern Sans-Serif)**
- Used for: Headers, UI elements, key terms
- Weight distribution: Regular (400) for body, Bold (700) for headers
- Download: Free from Google Fonts
- Reasoning: Clean, highly readable, modern without being trendy

**Secondary Font: IBM Plex Mono (Technical Monospace)**
- Used for: Code examples, metrics values, technical terms
- Weight: Regular (400)
- Download: Free from Google Fonts
- Reasoning: Professional technical aesthetic, excellent for data/code display

**Fallback Stack:**
- Inter → Segoe UI → Helvetica Neue → Sans-Serif
- IBM Plex Mono → Consolas → Courier New → Monospace

### 3.2 Typography Scale

| Element | Font | Size | Weight | Line Height | Color |
|---------|------|------|--------|-------------|-------|
| Video Title (Opening) | Inter | 54px | 700 | 1.2 | Navy #1F3A5F |
| Main Slide Title | Inter | 40px | 700 | 1.3 | Navy #1F3A5F |
| Section Header | Inter | 32px | 700 | 1.3 | Navy #1F3A5F |
| Subsection Header | Inter | 24px | 600 | 1.4 | Navy #1F3A5F |
| Body Text (Narration) | Inter | 18px | 400 | 1.6 | Cool Gray #495057 |
| Emphasis/Key Term | Inter | 18px | 600 | 1.6 | Teal #17A2B8 |
| Data Value | IBM Plex Mono | 20px | 700 | 1.4 | Navy #1F3A5F |
| Small Caption | Inter | 14px | 400 | 1.5 | Cool Gray #495057 |
| Annotation/Note | Inter | 12px | 400 | 1.4 | Cool Gray #495057 |

### 3.3 Text Styling Guidelines

**Headers:**
- All caps for section breaks? NO (use Title Case instead for readability)
- Line breaks: Use strategic breaks for readability (max 6-7 words per line in 40px font)
- Emphasis: Use teal color for key terms, not multiple font weights

**Body Text:**
- Max line length: 60 characters
- Line height: 1.6x font size (generous for video readability)
- Key terms: Highlight in teal or bold, never both simultaneously

**Code/Technical:**
- Always use IBM Plex Mono
- Syntax highlighting: Navy for keywords, Green for values, Orange for operators
- Include subtle background: Light gray (#F0F0F0) for code blocks

## 4. Visual Composition & Layout

### 4.1 Scene Composition Rules

**Rule 1: Third-Line Composition**
- Important elements positioned at third-line intersections (not center)
- Creates visual interest and guides viewer attention
- Exception: Symmetrical data dashboards may use center composition

**Rule 2: Breathing Room**
- Minimum 5% padding around all elements
- Never use full-bleed text
- White space = thinking time for learners

**Rule 3: Visual Hierarchy**
- Large elements: 60% navy/primary color
- Medium elements: 30% accent colors (teal/green/orange)
- Small elements: 10% supporting colors (gray/white)

**Rule 4: Consistency Grid**
- Align all elements to 8px grid
- Margins: 40px for main content, 20px for supporting elements
- This ensures professional polish and consistent spacing

### 4.2 Slide Layouts

**Layout 1: Title Slide**
```
[1/3 height - Navy background with Teal accent line]
Main Title (54px, white text)
Subtitle (24px, light gray text)
[2/3 height - Light background]
Visual representation of MEASURE loop (centered, 60% width)
```

**Layout 2: Content Slide**
```
[1/4 height] Navy header bar
Section title (32px, white), teal accent underline

[3/4 height] Light background
- Left side (60%): Text/diagram content
- Right side (40%): Supporting visual or data
- Minimum 20px gutter between columns
```

**Layout 3: Full Visual (Chart/Diagram)**
```
[1/6 height] Navy header bar
Title (28px, white text)

[5/6 height] Light background
Centered diagram (80% width max)
Caption below in small text (14px, gray)
```

**Layout 4: Comparison**
```
[1/4 height] Navy header bar
Title (32px, white text)

[3/4 height] Two-column layout
Left: Navy-bordered box (#1F3A5F border 3px)
Right: Teal-bordered box (#17A2B8 border 3px)
Each column 45% width, 10% gutter
```

**Layout 5: Process Flow**
```
[Full height]
Horizontal timeline with circular nodes
Nodes: Navy (#1F3A5F) with Teal connectors
Arrows between nodes: Teal gradient →
Labels below nodes: Gray text (14px)
```

### 4.3 Animation Principles

**Entrance Animations:**
- Fade-in for text: 400ms, no easing
- Slide-in for diagrams: 600ms, ease-out cubic
- Grow for circular elements: 500ms, ease-out back

**Emphasis Animations:**
- Pulse highlight: 800ms, returns to original state
- Color highlight: 300ms color change, 300ms return
- Border emphasis: 400ms border glow effect in teal

**Exit Animations:**
- Fade-out for text: 300ms
- Slide-out for diagrams: 400ms, ease-in cubic
- Shrink for circular elements: 400ms, ease-in back

**Loop Animations (for MEASURE loop and cyclical concepts):**
- Continuous rotation: 4000ms, linear, infinite
- Pulsing arrows: 1200ms, infinite, ease-in-out
- Cycling colors: 3000ms, steps(5), infinite

## 5. Graphic Elements & Icons

### 5.1 Icon Style Guide

**Icon Specifications:**
- Format: SVG (scalable, crisp at any size)
- Style: Outline only (no solid fills except data visualization)
- Stroke width: 2px for large icons (40px+), 1.5px for small icons (20-30px)
- Colors: Primarily Navy (#1F3A5F), with Teal accents for interactive elements

**Icon Library Categories:**

| Category | Examples | Color | Usage |
|----------|----------|-------|-------|
| Navigation | Arrow right, arrow down, expand | Navy | Process flows, progression |
| Systems | Circle with arrows, feedback loop, network | Teal | MEASURE loop, systems thinking |
| Data | Chart, dashboard, metric, gauge | Navy | Data visualization context |
| Success | Checkmark, tick, complete | Green | Achievement, success states |
| Action | Circle with play, record, start | Teal | Interactive elements |
| Attention | Alert, warning, exclamation | Orange | Areas needing attention |

### 5.2 Diagram Standards

**Systems Diagram Style:**
- Navy circular nodes (50px diameter) with 2px teal border
- Arrows: Teal (#17A2B8), 2px stroke, 20px arrowhead
- Labels: IBM Plex Mono, 14px, Navy, positioned above/below arrows
- Background: Light (#F8F9FA) with subtle grid lines (very light gray, 1px)

**Data Visualization Style:**
- Bars: Navy for baseline, Teal for current, Green for target
- Lines: Teal with 3px stroke, data points marked with 6px Navy circles
- Areas: Subtle gradient fills (80% opacity, Navy to Light Navy)
- Grid lines: Very light gray, 1px, dashed

**Timeline Style:**
- Horizontal line: Teal, 3px stroke
- Nodes: Navy circles, 16px diameter
- Completed nodes: Green background, white checkmark
- Current node: Teal background, pulsing animation
- Future nodes: Light gray background

**Comparison Boxes:**
- Left side: Navy border (3px), Light background
- Right side: Teal border (3px), Light background
- Headers: Navy background (left), Teal background (right)
- Content spacing: 20px padding, left-aligned text

### 5.3 Supporting Graphics

**Background Elements:**
- Subtle gradient: Top-to-bottom, Navy (10% opacity) to transparent
- Curved accent lines: Teal, 2% opacity, placed in corners/edges
- Grid pattern: Very light gray (1% opacity), 20px spacing

**Transitional Elements:**
- Divider lines: Teal, 2px, with Navy circles at 1/3 and 2/3 points
- Accent bars: Teal, 4px height, extends across full width
- Decorative shapes: Subtle rounded rectangles behind headers in 2% Navy

## 6. Data Visualization Standards

### 6.1 Chart Design

**Bar Charts:**
```
Navy bars for categories/comparison
Teal for current/active data
Green for success/target metrics
Orange for needs-improvement areas

Grid lines: Very light gray, horizontal only
Y-axis labels: 14px IBM Plex Mono, Navy
X-axis labels: 14px Inter, Navy
Title: 24px Inter Bold, Navy (above chart)
Legend: Bottom-right, 12px Inter, Navy
```

**Line Charts:**
```
Primary line: Teal, 3px stroke
Secondary lines: Navy, 2px stroke, dashed (if needed)
Data points: Navy circles, 6px diameter
Fill area: Teal gradient, 30% opacity
Axes: 1px Navy
Labels: 12px IBM Plex Mono, Navy
Title: 24px Inter Bold, Navy
```

**Pie/Donut Charts:**
```
Avoid when possible (hard to interpret exact values)
If necessary:
- Navy segment (largest, 50%+)
- Teal segment (30%)
- Green segment (smaller, success-related)
- Orange segment (smaller, improvement-related)
- Center label: Navy, 28px, Bold
- Outer legend: 12px, Navy
```

### 6.2 Dashboard Design

**Layout:**
- 3-column grid for main metrics
- Navy card borders (2px), light background
- Header: Navy background (30px height), white text (18px Bold)
- Value display: 36px IBM Plex Mono, Navy, centered
- Unit/label: 12px Inter, Gray

**Color Coding:**
- Green: Exceeds target (upward arrow in green)
- Navy: On track (neutral dash)
- Orange: Below target (downward arrow in orange)
- Teal: Changing/In progress (circular arrow)

**Spacing:**
- Card margins: 20px
- Internal padding: 15px
- Value-to-label gap: 8px
- Card height: 140px (fixed for alignment)

## 7. Animation & Motion Graphics

### 7.1 Motion Principles

**Timing Standards:**
- Short transition: 300-400ms (element appearance)
- Medium transition: 600-800ms (diagram reveal)
- Long transition: 1000-1500ms (complex animation sequence)
- Loop animation: 3000-4000ms (MEASURE loop, cycles)

**Easing Functions:**
- Entrance: ease-out-cubic (decelerate, natural)
- Emphasis: ease-in-out-cubic (smooth pulse)
- Exit: ease-in-cubic (accelerate away)
- Loop: linear (consistent cycle speed)

### 7.2 Key Animation Sequences

**Animation 1: MEASURE Loop Introduction**
```
Duration: 6 seconds total
- Frame 0-1s: Navy circle appears, grows to 200px (ease-out)
- Frame 1-2s: "MEASURE" text fades in around circle
- Frame 2-5s: Circular arrow rotation (teal, 4s duration, continuous)
- Frame 5-6s: Five segments light up sequentially (teal highlight, 200ms each)
- Loop continues: Gentle rotation + pulsing segments (4s cycle)
```

**Animation 2: Metric Flow Introduction**
```
Duration: 4 seconds
- Frame 0-1s: Navy box slides in from left (60% width)
- Frame 1-2s: "Input" label appears
- Frame 2-3s: Teal arrow animates left-to-right (ease-in-out)
- Frame 3-4s: Navy box slides in on right, "Output" label appears
```

**Animation 3: Three Types of Evaluation Reveal**
```
Duration: 3 seconds total
- Frame 0-1s: Nested circles appear (largest first, largest = Navy)
- Frame 1-2s: Middle circle appears and highlights in Teal
- Frame 2-3s: Inner circle appears and highlights in Green
- Stagger: 200ms between each circle entrance
```

**Animation 4: Data Dashboard Update**
```
Duration: 2 seconds per metric card
- Frame 0-0.5s: Card background color shift (subtle, 50% opacity change)
- Frame 0.5-1s: Value number counts up (IBM Plex Mono, animated)
- Frame 1-1.5s: Status icon appears and rotates (checkmark, arrow, etc.)
- Frame 1.5-2s: Icon holds steady, subtle pulse (100ms, 2% scale change)
```

### 7.3 Transition Between Scenes

**Standard Transition:**
- Duration: 300ms
- Effect: Fade out current scene, fade in next (simultaneous, creates smooth crossfade)
- Color: Black intermediate (optional, for dramatic emphasis on key scene breaks)

**Emphasis Transition (for key concepts):**
- Duration: 600ms
- Effect: Current scene dissolves into particles (teal-colored), particles coalesce into new scene
- Only used 2-3 times per video for maximum impact

**Flow Transition (for related concepts):**
- Duration: 400ms
- Effect: Slide transition (direction matches content progression: left-to-right)
- Used when showing progression, cause-effect, timeline

## 8. Voiceover & Audio Visual Sync

### 8.1 Visual Cues for Voiceover Sync

**Narration pacing:**
- Each on-screen element appears 200ms before narration mentions it
- Key emphasis points highlighted in teal (300ms animation) matching vocal emphasis
- Silence in narration matched with 500-800ms animation holds (lets audience read/absorb)

**Audio-visual synchronization:**
- Background music: Starts at 50% volume, ducks to 30% during narration
- Transition sounds: 150ms subtle whoosh (teal-colored visual transition)
- Data reveal sounds: 200ms rising tone matched to animation reveal
- Completion sounds: 300ms satisfying "ding" sound matched to green success icon

## 11. Production Quality Standards

### 11.1 Resolution & Technical Specs

**Video Resolution:** 1920x1080 (16:9 aspect ratio, Full HD)
- Ensures compatibility with LMS, YouTube, mobile platforms
- Minimum bitrate: 5000 kbps for streaming, 8000 kbps for download

**Color Space:** sRGB (not ProPhoto, not Adobe RGB)
- Standard for web delivery and viewing on diverse displays
- Ensures Navy appears as #1F3A5F on all displays

**Frame Rate:** 30fps (not 24fps for educational content)
- 30fps is standard for streaming platforms and clearer motion in animations
- Ensures smooth rendering on both 30fps and 60fps displays

**Text Minimum Size:** 18px (Body), 24px (Headers)
- Readable on screens as small as tablets (7-10 inches)
- Legible when viewed as standard YouTube embed on desktop

### 11.2 Quality Checklist (Per Scene)

- [ ] All text readable (18px minimum, high contrast)
- [ ] Color palette used correctly (no off-brand colors introduced)
- [ ] Icons: Consistent stroke width, proper sizing (40px+ for prominence)
- [ ] Animations: Smooth, no jittering, proper easing applied
- [ ] Diagram alignment: All elements on 8px grid, no floating/offset elements
- [ ] Typography: Correct fonts applied, no font substitutions
- [ ] Spacing: Consistent padding (40px margins, 20px internal gutters)
- [ ] Data accuracy: All numbers, dates, metrics match source material
- [ ] Voiceover sync: Visual elements appear 200ms before narration mentions them
- [ ] Transitions: Smooth, consistent 300-600ms timing
- [ ] Audio levels: Background music at 30%, voiceover at 100%

## 12. Distribution & Format Variations

### 12.1 Platform-Specific Adaptations

**YouTube Full Videos (4 videos, 50+ minutes):**
- Resolution: 1920x1080, 30fps, 8000 kbps
- Thumbnail: 1280x720, Navy background, Teal accent, title text (20px+ size)
- Typography remains, no resizing needed

**Short-Form Clips (13 clips, 3-5 minutes each):**
- Resolution: 1080x1080 (vertical square, for Instagram/TikTok)
- Recompose layouts: Center-focus, padding on sides in Navy
- Typography: Larger (accommodate viewing on phone screens)
- Motion: More dynamic, shorter transitions (easier to watch in 15s bursts)

**LMS Embedded (Taleemabad platform):**
- Resolution: 1280x720 (smaller than full 1080p)
- Color profile: Verify Navy and Teal appear correct after LMS compression
- Typography: Verify 18px minimum remains readable at smaller player size
- Add chapter markers (MEASURE loop segments)

**Accessibility/WCAG Compliance:**
- All text: 4.5:1 minimum contrast (Navy on light = 9.5:1 ✓)
- Color not sole indicator: Always pair colors with icons/text labels
- Captions: Burned-in subtitles at 18px, positioned bottom-center
- Audio descriptions: Separate track describing visual elements for blind learners

## 13. Revision & Iteration Protocol

### 13.1 Feedback Integration

When user/stakeholder feedback arrives:
1. **Color feedback:** Only adjust after testing RGB values on multiple displays
2. **Typography feedback:** A/B test proposed changes on full slides before final approval
3. **Animation feedback:** Record 30-second preview animations before full video production
4. **Layout feedback:** Create prototype static screenshots before animation investment

### 13.2 Version Control

- Keep master mood board in `Systems_Evaluations_Mood_Board_Specification.md`
- Version updates documented at end of document (Date, Change, Reason)
- Visual assets versioned in subfolders: `v1_approved/`, `v2_iterations/`, `v3_final/`
