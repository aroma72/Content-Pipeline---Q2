# Systems Evaluations Video Series — Production Timeline & Checklist
**8-Week Production Schedule: May 7 - June 25, 2026**

---

## Overview

This document provides a detailed day-by-day production timeline for the 4-part Systems Evaluations video series. It coordinates work across four simultaneous production tracks:

1. **Voiceover Recording** (Week 1-2)
2. **Animation Creation** (Week 1-5)
3. **Screen Recording & B-Roll** (Week 2-3)
4. **Post-Production & Publishing** (Week 6-8)

**Production Phases:**
- **Phase 1 (Weeks 1-2):** Pre-production finalization, material approval
- **Phase 2 (Weeks 3-5):** Active production (recording, animating, gathering media)
- **Phase 3 (Weeks 6-7):** Post-production (editing, color grading, audio mixing, captions)
- **Phase 4 (Week 8):** QA, distribution, short-form clips generation

## Risk Management

### High-Risk Items (Monitor Closely)

**Risk 1: Voiceover quality issues**
- Mitigation: Multiple takes per scene, voice coach present
- Contingency: Budget for voiceover re-recording (1-2 days)

**Risk 2: Animation delays (most complex phase)**
- Mitigation: Animator starts Week 1, approvals on Week 1-2 timeline
- Contingency: Reduce animation complexity for lower-priority sequences

**Risk 3: Sync issues between voiceover and visuals**
- Mitigation: Create timing spreadsheet, 200ms lead-time specification
- Contingency: Editor has flex room to adjust visual timing (±200ms)

**Risk 4: Rendering bottleneck (Week 5-6)**
- Mitigation: Start renders early, schedule overnight renders
- Contingency: Access to backup rendering hardware/cloud rendering if needed

**Risk 5: Color grading inconsistency**
- Mitigation: Apply LUT to all videos, color reference on multiple displays
- Contingency: Professional color grader review (1-2 day adjustment window)

### Medium-Risk Items

**Screen recording failures** → Keep backup screen recordings from different tools
**Subtitle sync errors** → Manual verification against voiceover (scheduled Week 7)
**Platform compatibility issues** → Test on LMS early (Week 7 testing phase)
