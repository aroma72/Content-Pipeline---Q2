decision.md

Build your decision log — a record of your choices, and the reasons behind them.

What you're making

decision.md captures the choices you make in your project — and why you made them. It's different from the journal: the journal captures lessons (often from mistakes); the decision log captures choices, on purpose. Write the "why" down, and neither you nor your agent has to second-guess a good choice weeks later.

Your task

Ask Claude Code to create the file for you — don't write it all by hand.
💬 Where do you do this? In the Claude Code chat. Claude Code is the AI assistant that works right inside your project, and its chat box — the text box where you type — is where you talk to it. So: open your project in Claude Code, click into the chat box at the bottom, type or paste the instruction below, and press Enter to send it. Claude replies in that same chat and creates the file for you. Every step of this exercise happens in that chat.
Send a message like this:
"Create a decision.md log for this project. Capture 3 real decisions we've made — for each, write what we decided, why, and what we ruled out."
Then read the file Claude made and tally it against the three questions below. Your job is to review and verify — not to write it all yourself.

Read & tally — does each entry answer…

  1. ☐ What did you decide?
  2. ☐ Why was it the right call?
  3. ☐ What did you consider, but rule out?

Check they're real decisions with a genuine trade-off — not trivial ones. If a decision is trivial or a "why" is missing, send it back: "This one has no real trade-off — replace it, and add the reasoning for decision 2."

💡 Hint — how to do it

Refresher — what "good" looks like (your yardstick when reviewing Claude's file)

Three lines is a complete entry. Think of a doctor's notes — not just what happened, but why this over another. Use the example below to judge whether each decision Claude logged is real and worth keeping.

Example
# decision.md

2026-06-18 — where to store learner data
Decided: keep it in a simple spreadsheet, not a big database.
Why: it's small, and only I use it.
Considered: a database — but overkill for now.
Tip: your agent sees what you did, but never why. This file is how it (and future-you) finally knows the reasoning.

📤 Final step — push it to GitHub

Once Claude has created your file, commit and push it to your existing project's GitHub repository — the same project you've been working in this week, not a new repo. From your project folder:

git add decision.md
git commit -m "Add decision.md log"
git push
✅ Done when: decision.md (created by Claude Code, reviewed and tallied by you) has 3+ entries that pass the three questions — and it's pushed to GitHub.
