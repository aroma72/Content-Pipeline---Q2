Agent Loop Feedback Task

Week 3 · The Mindset Shift — Practical Assignment (SLO 1.7: the Agent Loop)

Goal

Show that you understand how an autonomous agent improves through a feedback loop — not by answering once, but by acting, seeing what happened, and adjusting.

Task

Use Claude Code to create a file named agent_loop.md.

In the file, explain this simple agent loop:

Observe→ Decide→ Act→ Get Feedback→ Improve↻
EXAMPLE SCENARIO

A learner named Ayesha has not logged in for 9 days and has completed only 1 out of 4 assignments.

The agent first recommends:

“Send Ayesha a reminder email.”

Then feedback comes in:

“Ayesha did not respond to the email.”

Now the agent must improve its next action.

What to include in your file

  1. What did the agent observe?
  2. What action did the agent recommend first?
  3. What feedback did the agent receive?
  4. How did the agent improve the next recommendation?
  5. In 2–3 lines, explain how this is different from a normal chatbot.

Claude Code prompt

Submission

Submit the file by pushing the project commit to GitHub.

Remember: the power of an agent isn't the first answer — it's what it does with the feedback. A chatbot stops at “Act.” An agent keeps looping: Observe → Decide → Act → Get Feedback → Improve.
