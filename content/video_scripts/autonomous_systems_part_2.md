## KEY CONCEPTS TO COVER IN VOICEOVER

1. **Testing Definition**
   - Checks if system functions work
   - Verifies code correctness
   - Technical validation
   - Answers: "Does it work?"

2. **Evaluation Definition**
   - Checks if system is appropriate for real-world use
   - Considers fairness, safety, ethics
   - Verifies impact on users
   - Answers: "Is it right?"

3. **Real-World Example**
   - A system can PASS all tests
   - But still FAIL evaluation criteria
   - Because it introduces bias/harm
   - This is why evaluation is essential

4. **Why Both Matter**
   - Testing ensures it works
   - Evaluation ensures it should work
   - Both are necessary, not optional
