## KEY CONCEPTS TO COVER IN VOICEOVER

1. **Skills as Foundation**
   - Agent capabilities are the first building block
   - Skills are composable functions
   - Can call other skills recursively
   - Each skill has specific purpose and constraints
   - Skills enable the agent to act in the world

2. **Evaluation Hooks as Conscience**
   - Hooks run in real-time alongside execution
   - Like safety guards and permission systems
   - Ask "is this safe before we do it?"
   - Can stop execution if threshold crossed
   - Three types: pre-check (before), parallel (during), post-check (after)

3. **Self-Improvement Loops**
   - Agent learns from outcomes of actions
   - Feedback flows back to improve future decisions
   - Reflection on what worked and what didn't
   - Continuous adaptation based on results
   - System gets better over time, not just executing

4. **Integration of All Three**
   - Skills provide capability and direction
   - Hooks ensure safety and appropriateness
   - Feedback enables continuous learning
   - Together: autonomous system that acts, evaluates, learns, improves
   - No single piece works alone—all three required

5. **Practical Implementation**
   - Skills in agents/ folder
   - Evaluation hooks in hooks/ or middleware
   - Feedback mechanisms in logging/monitoring
   - Orchestrator ties them together
   - Each component testable and improvable independently
