# RemotionVideoAgent Self-Validation Loop

**Date**: 2026-05-21  
**Status**: ✅ Integrated and ready  
**Purpose**: Validate generated Remotion code against locked rules BEFORE rendering

---

## Overview

**LOCKED: No invalid code reaches the renderer.** After Claude generates TSX/JSX composition code, the agent validates it against all locked rules. If violations are found, Claude rewrites the code automatically (max 2 attempts). If validation still fails, the violation is logged to `agent_memory.json` for human review and the pipeline halts.

---

## Where It Fits in RemotionVideoAgent Flow

### High-Level Flow

```
_execute()
  ├─ For each video:
  │   ├─ _build_multi_scene_composition() ← GENERATES CODE
  │   │   ├─ Claude generates TSX/JSX
  │   │   ├─ Remove markdown formatting
  │   │   ├─ NEW: _self_validate_composition_code() ← VALIDATES CODE (max 2 attempts)
  │   │   │   ├─ Attempt 1: Send to Claude with locked rules
  │   │   │   │  ├─ If APPROVED → return code
  │   │   │   │  └─ If violations → rewrite and retry
  │   │   │   ├─ Attempt 2: Validate rewritten code
  │   │   │   │  ├─ If APPROVED → return code
  │   │   │   │  └─ If violations → log to agent_memory.json and HALT
  │   │   │   └─ Return validated code OR None
  │   │   └─ Return to _execute()
  │   ├─ Register composition (only if validation passed)
  │   ├─ Verify locked rules (frame count, duration, etc.)
  │   └─ Render with Remotion (only reached if all checks pass)
  └─ Return assembled videos
```

## Validation Loop Logic

### Attempt 1
```
Current code = Generated composition code
↓
Send to Claude with validation prompt
↓
Claude analyzes against locked rules
↓
Does code pass?
├─ YES: Log "APPROVED" and return code ← SUCCESS
├─ NO: Extract violations and rewritten code
│      ↓
│      Does rewritten code exist?
│      ├─ YES: Extract it, increment attempt counter
│      └─ NO: Log error, return None ← FAIL
```

### Attempt 2
```
Current code = Rewritten code from Attempt 1
↓
Send to Claude with validation prompt (same rules)
↓
Claude analyzes rewritten code
↓
Does code pass?
├─ YES: Log "APPROVED (Attempt 2)" and return code ← SUCCESS
├─ NO: Extract violations again
│      ↓
│      attempt > 2?
│      ├─ YES: Log to agent_memory.json, return None ← FAIL
│      └─ NO: [Not reached; this is final attempt]
```

## Error Recovery Scenarios

### Scenario 1: No Rewritten Code Provided
Claude lists violations but doesn't provide fixed code.

**Action**: 
- Log error
- Log violation to agent_memory.json
- Return None
- Pipeline halts

```
log_error("RemotionVideoAgent", "ValidationNoRewrittenCode",
         "Video 1: Claude found violations but no rewritten code provided")
```

---

### Scenario 2: Unexpected Response Format
Claude's response doesn't match expected format (neither "APPROVED" nor "VIOLATIONS:").

**Action**: 
- Log error with first 200 chars of response
- Log violation to agent_memory.json
- Return None
- Pipeline halts

```
log_error("RemotionVideoAgent", "ValidationResponseFormat",
         "Video 1: Unexpected validation response format")
```

---

### Scenario 3: Exception During Validation
API call fails, JSON parsing fails, or other exception.

**Action**: 
- Catch exception
- Log to agent_memory.json
- Return None
- Pipeline halts

```
self.memory_manager.log_new_mistake("RemotionVideoAgent", {
    "correction_type": "VALIDATION_EXCEPTION",
    "video_number": 1,
    "timestamp": "...",
    "error": "[Exception message]",
    "action": "Self-validation threw exception. Manual review required."
})
```

## Integration in _execute()

**Location**: Lines 139-145 in `_execute()` method

**Code Flow**:
```python
# Step 1: Generate composition code for all scenes
composition_code = self._build_multi_scene_composition(video_number, scenes, config)

if not composition_code:  # ← Returns None if self-validation failed
    failed_videos.append(video_number)
    continue  # Skip this video; move to next

# Step 2: Register composition (only reached if validation passed)
comp_id = f"Video-{video_number}"
registration_success = await self._register_composition(comp_id, composition_code)
```

**Safety Gate**: If validation fails, `composition_code` is None, and the video is added to `failed_videos`. It never reaches registration or rendering.

## Agent Memory Logging

When validation fails after 2 attempts, the violation is recorded to `agent_memory.json` for the next human review:

**Format**:
```json
{
  "correction_type": "COMPOSITION_VALIDATION_FAILED",
  "video_number": 1,
  "timestamp": "2026-05-21T14:32:15.123456",
  "violations": [
    "ANIMATION_SEGMENT_DURATION_MAX: Scene 2 Sequence is 8s (max 6s allowed)",
    "ANIMATION_INTERNAL_MOTION: Scene 3 has only 1 animation (needs 2+)"
  ],
  "attempts": 2,
  "last_code": "[first 500 characters of final attempted code]...",
  "action": "Composition code failed self-validation. Manual review required before rendering."
}
```

**Human Action**:
- Review `agent_memory.json` past_mistakes for RemotionVideoAgent
- Examine the violations and the last code attempted
- Manually fix the composition code
- Re-run the pipeline with corrected code

## Attempt Counter Logic

```python
attempt = 1  # Start at 1

while attempt <= 2:  # Loop runs max 2 times
    # Validation attempt...
    
    if "APPROVED" in response:
        return current_code  # Success on this attempt
    
    if "VIOLATIONS:" in response and "REWRITTEN CODE:" in response:
        current_code = rewritten_code
        attempt += 1  # Increment for next iteration
        
        if attempt > 2:  # Check BEFORE next iteration
            # Log to memory and fail
            return None
        # Continue loop to Attempt 2
    else:
        # Unexpected response, fail immediately
        return None

# Should not reach here
return None
```

## Key Design Decisions

1. **Max 2 attempts**: Enough for most corrections; beyond that, human review is needed
2. **Pre-render validation**: Prevents bad code from reaching expensive render step
3. **Memory logging**: Creates audit trail of all failures for root cause analysis
4. **Strict response parsing**: If Claude's response doesn't match expected format, fail safely
5. **No silent passes**: Even if code generates without errors, it must pass locked rule validation
