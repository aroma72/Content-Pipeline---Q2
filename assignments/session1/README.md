# Session 1 Assignments - Agentic AI Mastery

## Ready to Share

Two minimal, clean assignment PDFs for Session 1 of the Agentic AI Mastery cohort.

---

## **Assignment 1: Theory**
**File:** `Session1_TheoryAssignment.pdf` (2.5 KB)

**Title:** Design an Agent for Your Workflow

**Format:** Title + Instructions + Question + End

**Task:** Students pick a recurring 4+ hour/week task and design an agentic solution:
- What's the problem?
- How would an agent solve it?
- Where does human judgment stay essential?
- How would you measure success?
- When would you trust it to run alone?

**Time:** 60-90 minutes

**After:** Videos 1 & 2 (Cohort Introduction, What is an AI Agent?)

---

## **Assignment 2: Practical**
**File:** `Session1_PracticalAssignment.pdf` (2.5 KB)

**Title:** Build Your First Tool in Agent Mode

**Format:** Title + Instructions + Question + End

**Task:** Students build ONE practical tool with Cursor's Agent mode:
- Option A: Data processing script
- Option B: Automation script
- Option C: Custom tool for their workflow

Submit: Code + Screenshots + 300-word reflection

**Time:** 90-120 minutes

**After:** Video 3 (Claude Code Setup)
