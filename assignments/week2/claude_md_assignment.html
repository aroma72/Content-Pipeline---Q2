Assignment

Create a CLAUDE.md for one of your own projects.
It is the file your agent reads first, every time — the “drawing room” it walks into. Keep it tidy and under 50 lines, and make it specific enough that a stranger could read it cold and work the way you would in thirty seconds.

Don't describe a project in the abstract — write the actual file, as if you were handing it to an agent tomorrow morning.

HINT · REFRESHER

What a CLAUDE.md is

A short plain-text file your agent reads before it does anything — your standing orientation: who you are, how you work, and what not to do. It loads into the agent's limited working memory every task, so keep it under ~50 lines. Short isn't lazy — it's respect for a real limit.

The four parts of a great one

1Purpose — what this project is, in a sentence or two. e.g. “We turn class recordings into short lessons for teachers.”
2Hard rules — your non-negotiables. Be specific. e.g. “Never share learner data.” “Always ask before deleting a file.”
3Pointers — where things live. Don't paste everything in; point to it. e.g. “Formatting rules are in the docs folder.”
4How you like work done — tone, formats, what “good” looks like. e.g. “Write in simple English. Short paragraphs. Define every new term.”

How to write it

  • Start small — five lines is fine on day one.
  • Grow from mistakes — each time the agent misreads something, add the one line that would have prevented it.

Avoid the three traps

  • Length — pasting in everything and drowning the file.
  • Vagueness — “write well” tells the agent nothing.
  • Staleness — rules that describe last month's project, not this one.

The test for a great one

Read cold by a stranger, it should let them work like you in thirty seconds. Trim it like packing a small bag for a trip — only what you'd genuinely miss.

A tiny example to model (not to copy)

● ● ●  CLAUDE.md  11 / 50 lines
# CLAUDE.md ## Purpose We turn class recordings into short lessons for teachers. ## Rules — never break - Never share learner data. - Always ask before deleting a file. ## Where things live - Formatting rules → the docs folder ## How we work - Write in simple English. - Short paragraphs; define every new term.
