Technical reference

Everything needed to drive video creation from the LMS and to render the in-video checkpoint. Base URL https://content-queen-production.up.railway.app. Two separate APIs: an unauthenticated job API for creating a video, and a token-gated read API for consuming its checkpoint.

Supersedes the course-builder reference of September 2026.
The /api/v1/courses/* endpoints still answer, but nothing has been built on them and they are not the supported path. Build against the endpoints in this document. The unit of work is one video, created and approved individually.

Two different rules, because the two APIs carry different risk.

2 · Creating a video — the job API

Four calls. Writing is free and fast; producing costs money and takes half an hour; publishing needs a human. Each is a separate request so each is a separate decision.

 EndpointReturns
POST/demo/make-video202 + {jobId, status}. Body: {"topic": "..."}. Starts research → script → gate.
GET/demo/make-video/:jobIdJob state. Poll every 4–5s. Carries the script once written.
POST/demo/make-video/:jobId/produce202. Spends money. Art, voice, render, QA. Body {"publish": true, "by": "name"} supplies the approval up front and skips the pause; omit it and the run stops at awaiting_review.
GET/demo/make-video/:jobId/videoThe finished MP4. Honours Range, so it scrubs in a player.
POST/demo/make-video/:jobId/approve202. Publishes to YouTube. Body: {"by": "name"}.
GET/demo/make-video/:jobId/script.mdThe script as a Markdown file, with Content-Disposition set so a browser saves it. Every beat, plus the checkpoint with its answer and explanation.
GET/demo/sampleThe pinned demo topic, and the committed worked example if one has been captured.
POST /demo/make-video          // free, returns immediately
Content-Type: application/json
{ "topic": "how do I handle an angry parent on the phone" }

→ 202 { "jobId": "8fb136e2012c", "status": "running" }

The job is created and the request returns at once. Writing a gated script takes three to seven minutes, which is far too long to hold a connection open — an edge proxy will cut it. Poll instead.

3 · The job lifecycle

status is what to branch on. stage is for showing progress and will move backwards during a redraft, which is normal.

statusMeaningWhat the UI should do
runningResearching, writing or gating.Show stage. Keep polling.
writtenScript done and passed the gate.Render script. Offer the produce button.
producingArt, voice, render, QA. A quality gate may send the script back for up to 2 rounds; the stage name moves backwards while it does, which is normal.
awaiting_reviewThe video is finished. Not published.Play /video. Offer the approve button.
publishingUploading to YouTube.Keep polling.
publishedLive, unlisted.Show produce.youtube.url.
failedThe run stopped. error says where and why.Show the error. The topic can be retried.

awaiting_review is a success state, not a failure

The video exists and passed QA. Treating it as an error is the most likely integration mistake — it is the state the pipeline is designed to end in, and only a person moves it on. produce.status mirrors it, and produce.spendUsd says what it cost.

7 · Five fields to respect

FieldRule
atSecondsFire here. Measured from the start of the delivered file, brand intro included. Using lessonAtSeconds instead fires ~2.6s early.
timing.trustedIf false, do not fire. A beat length was not measured, so every time after it is a guess.
pause.safeIf false, do not fire. The checkpoint has no spoken sentence on one side, so there is no boundary to pause on.
rendersInVideoOlder videos (true) also draw the question on screen, so the popup duplicates it — you may prefer to let those play. New videos are always false.
explanationSourceauthored = written for a learner who chose wrong. video-note = a short on-screen caption, thin as feedback. missing = show nothing but the correct answer.
Two guards, and both must pass.
timing.trusted && pause.safe. Either being false means the firing time is not dependable, and a popup landing mid-sentence is worse than no popup. Fail closed: play the video straight through.

9 · Firing the popup

// Fetch server-side; the token must never reach the browser.
const { timing, checkpoints } = await api.checkpointsFor(videoId);

// Fail closed. An untrusted time is worse than no popup.
const live = timing.trusted
  ? checkpoints.filter(c => c.pause.safe).sort((a, b) => a.atSeconds - b.atSeconds)
  : [];

let next = 0;
player.on('timeupdate', () => {
  const c = live[next];
  if (!c || player.currentTime < c.atSeconds) return;
  next++;                       // before showing, so a re-entrant tick cannot double-fire
  player.pause();
  showCheckpoint(c);            // preamble, stem, options — your own UI
});

function onAnswer(c, chosen) {
  const right = chosen === c.correctIndex;
  record({ videoId, checkpointId: c.id, chosen, right });   // YOUR store
  if (right) return resumeAfterBrieflyConfirming();
  // Wrong: the explanation is the whole point. Show it with the correct
  // option marked, and let them continue — never block progress on it.
  showExplanation(c.explanation, c.options[c.correctIndex]);
}
  • Seeking. A learner who scrubs past a checkpoint should not have it fire retroactively. Recompute next from currentTime on seeked.
  • Once per view. Do not re-fire a checkpoint the learner has already answered in this sitting.
  • Never a dead end. A wrong answer shows the explanation and continues. Gating progress on a formative check turns a teaching moment into an exam.

11 · Failure modes worth handling

SymptomCause and response
503 on any /api/v1 routeThe server has no token configured. It fails closed rather than serving openly. Ours to fix; check GET /api/v1 for configured.
404 on a videoId that workedWe keep no disk between releases. A video registered at runtime is gone after a deploy. Persist the checkpoint payload when you first read it.
deliverableOnServer: falseExpected, not an error. Video files are not committed to our repository. The YouTube link is the durable copy.
429 on make-videoSix videos per hour per IP. Creation spends real money.
status: failed mid-produceA quality sensor rejected the work and the redraft budget ran out. The topic can be retried; the error names the stage and the finding.
Stuck in awaiting_reviewNot stuck. It is waiting for a person, indefinitely and by design.
The single most important line in this document.
Our container has no persistent volume. Read the checkpoint payload once and store it with your content record. Do not call our API at playback time for every learner — cache it at publication, and treat our service as the source of truth at authoring time only.
