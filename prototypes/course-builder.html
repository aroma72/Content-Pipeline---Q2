Course Builder

Type a topic. Add as much or as little as you like. It plans the whole course — modules, lessons, a learning outcome and a check question for each — then hands every lesson to the video pipeline.

Held in this tab only, never stored. The same CONTENT_API_TOKEN the API uses.

Running scenario:
    Building is not wired to this button. Planning is free; building every lesson into a finished video costs real money and hours of machine time, so it is a separate API call that refuses unless the caller confirms the exact lesson count — POST /api/v1/courses/build. See the technical handoff.
